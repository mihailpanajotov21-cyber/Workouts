# Тренировки

Домашни тренировки с дъмбели за Михаил, мама и татко: упражненията подред с 3D анимация, почивки, история по седмица, месец и година.

Инсталира се от Chrome на телефона (менюто ⋮ → „Инсталирай приложението“) и работи и без интернет. Входът е с име и парола (Firebase Authentication), историята се пази във Firestore.
